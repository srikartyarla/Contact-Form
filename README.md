# Contact Form

A contact form built from scratch using semantic HTML5 and CSS.

## Features

- Name and email inputs with validation
- Country dropdown selector
- Message textarea
- Terms and conditions checkbox
- Form submission with `required` field validation

## What I learned

- Semantic HTML structure using `<form>`, `<label>`, `<input>`, `<select>`, and `<textarea>`
- Importance of `name`, `id`, and `for` attributes in forms
- Native browser form validation using `required` and `type` attributes

## Tech stack

- HTML5
- CSS3
